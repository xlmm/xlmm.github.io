二、PAI 思维技能（16 项）

Algorithm v6.3.0 闭合枚举，Algorithm 根据任务需要自动选用。

2.1 深度分析类

IterativeDepth — 对同一问题进行 2-8 轮不同科学视角的结构化多角度分析。4 轮通常能发现比直接分析多 30-50% 的需求。

  • 触发：iterative depth, multi-angle, deep dive, what am I missing
  • 适用：有预算的重要任务、从未做过的任务

ApertureOscillation — 3 轮范围振荡（窄/战术 → 宽/战略 → 综合），暴露单一缩放级别不可见的设计张力。

  • 触发：aperture oscillation, zoom in/out, tactical vs strategic, scope negotiation
  • 适用：架构决策、功能需对齐系统愿景时

SystemsThinking — 冰山模型、因果循环图、Meadows 12 杠杆点分析复杂系统结构。

  • 触发：systems thinking, causal loop, leverage points, why does this keep happening
  • 适用：反复出现的问题、“修复"产生新问题、大规模干预前

RootCauseAnalysis — Five Whys / 鱼骨图 / 故障树 / IS-IS NOT 结构化事故调查。核心公理：人不是根因，系统允许错误发生。

  • 触发：root cause, RCA, 5 whys, fishbone, postmortem, incident analysis
  • 适用：事故调查、反复缺陷、事后复盘

2.2 创意生成类

BeCreative — 通过 Verbalized Sampling 发散生成，单次产出 5 个多样候选，选最强。7 种工作流（标准/最大/树状/领域/技术/SyntheticData）。

  • 触发：be creative, brainstorm, divergent ideas, tree of thoughts, unconventional approach
  • 适用：需要创意脑暴、非传统方案、扩展数据集

Ideate — 进化式 9 阶段多周期创意引擎（消费/做梦/白日梦/沉思/偷窃/交配/测试/进化/元学习），产出真正新颖的想法。

  • 触发：ideate, novel ideas, evolve ideas, innovate, breakthrough ideas
  • 适用：需要突破性想法、有充足预算、BeCreative 不够时

2.3 推理框架类

FirstPrinciples — 马斯克式物理学推理：拆解到基本真理 → 挑战每个假设 → 从零重建。三步：DECONSTRUCT / CHALLENGE / RECONSTRUCT。

  • 触发：first principles, fundamental truths, challenge assumptions, rebuild from scratch
  • 适用：挑战"这真是约束还是习惯”、从零重建设计

Science — 科学方法作为通用算法：定目标 → 生成至少 3 个假设 → 设计可证伪实验 → 诚实测量 → 迭代。

  • 触发：experiment, hypothesis, science, how do we test
  • 适用：需要严格验证、快速诊断、设计实验

2.4 对抗与辩论类

Council — 多智能体辩论，为每个话题临时组建定制领域专家团，多轮可见对话产生智力摩擦。

  • 触发：council, debate, multiple perspectives, weigh options, what would experts say
  • 适用：复杂决策需多领域视角、重要策略审议

RedTeam — 32 并行专家对抗分析，攻击想法弱点，产出钢人论证 + 反论证。找弱点，非找人错。

  • 触发：red team, attack idea, counterarguments, stress test, devil's advocate
  • 适用：压力测试策略、投入前"打孔找问题"

2.5 质量与评估类

Evals — AI Agent 评测框架，三种评分器（代码/模型/人类）+ pass@k 评分。

  • 触发：eval, benchmark, regression test, compare models, pass@k
  • 适用：运行评测、对比模型/prompt、回归测试

BitterPillEngineering — 审计 AI 指令集过度提示，五问每条规则，分类为 CUT/RESOLVE/MERGE/KEEP 等。核心原则：越少脚手架 = 越好输出。

  • 触发：BPE, bitter pill, audit setup, over-prompting, trim instructions
  • 适用：清理 CLAUDE.md、检查冗余规则、token 浪费统计

2.6 全局视角类

WorldThreatModel — 对抗 11 个时间跨度（6 月到 50 年）的世界模型，含地缘政治/技术/经济/社会/环境/安全/野卡。

  • 触发：world model, test idea, future analysis, time horizon, long-term risk
  • 适用：评估长期策略韧性、高风险战略决策

ContextSearch — 两阶段上下文搜索（会话注册表 → git 历史），冷启动恢复。

  • 触发：context search, prior work, previous sessions, cold start, resume
  • 适用：恢复中断工作、查找之前 session

2.7 核心原语

ISA — 理想状态工件，将"完成"表达为可测试标准（ISC）。Algorithm 在 OBSERVE 阶段自动调用。

  • 触发：ideal state, ISA, ISC, project spec, articulating done
  • 适用：明确"什么算做完"、搭建项目规格

Fabric — 240+ 专门化 prompt 模式库（提取/总结/分析/创作/改进/安全/评分）。

  • 触发：fabric, extract_wisdom, summarize, analyze claims, improve writing, create mermaid diagram
  • 适用：从内容提取智慧、威胁建模、改进写作、代码审查、创建图表

三、PAI 系统/基础设施技能（15 项）

PAI Life OS 的运维和管理工具。

ISA — Algorithm 核心，每次任务自动调用。12 节锁定结构，ISC 作为可测试标准。

PAIUpgrade — PAI 自升级机制。4 并行线程（历史审计 + 用户上下文 + 来源收集 + 内部反思）生成优先级排序的升级建议。定期跑。

  • 触发：upgrade, PAI upgrade, check Anthropic, algorithm upgrade

Agents — 自定义代理组合系统。通过基础特质 + 语音 + 专长组合定制代理。

  • 触发：custom agents, compose agent, agent voices
  • 注意：代理团队/群集用 Delegation

Delegation — 6 种并行模式：内置代理、工作树隔离、后台、自定义、团队、并行分发。3+ 独立工作流时 Algorithm 自动调用。

  • 触发：parallel execution, agent team, spawn agents, fan out, divide and conquer

Knowledge — PAI 知识档案管理，4 域（人物/公司/想法/研究），支持搜索/添加/收割/开发/导入/矛盾检测/图谱导航。

  • 触发：knowledge, knowledge base, search knowledge, add to knowledge

CreateSkill — PAI 技能开发生命周期：结构轨道（scaffold/validate/canonicalize）+ 效果轨道（test/improve/optimize）。

  • 触发：create skill, new skill, validate skill, improve skill

Prompting — 元提示词标准库。Handlebars 模板系统 + RenderTemplate.ts。产出 prompt，非最终内容。

  • 触发：meta-prompting, template generation, prompt engineering, write a prompt for

Interview — 分阶段对话式访谈遍历所有 PAI 上下文文件（TELOS → IDEAL_STATE → 偏好 → 身份）。

  • 触发：/interview, start interview, review TELOS, quarterly context refresh

Telos — 人生操作系统与项目分析：管理目标/信仰/智慧/书籍/电影，McKinsey 式报告和仪表盘。

  • 触发：Telos, life goals, projects, books, beliefs, wisdom

Migrate — 从外部来源导入内容，按 PAI 分类自动路由（≥70% 自动，40-70% 确认，<40% 引导）。

  • 触发：/migrate, migrate content, import, bulk import

Loop — 迭代改进循环，多轮 Algorithm 周期，每轮间人工审核。

  • 触发：loop, iterate, refine, multiple passes, keep improving

Optimize — 自主优化循环，代码用指标驱动，技能/prompt 用 LLM-as-judge 评估。

  • 触发：optimize, hill climb, improve performance, benchmark

Daemon — 管理公共数字形象，自动聚合 PAI 内容，安全过滤后发布。

  • 触发：daemon, update daemon, daemon profile, deploy daemon

Security — 安全评估：网络侦察、Web 应用测试、提示注入测试、安全新闻监控。

  • 触发：recon, port scan, pentest, OWASP, prompt injection, security news

Thinking — 多模式思维路由枢纽，将请求分发到 FirstPrinciples / IterativeDepth / BeCreative / Council / RedTeam / WorldThreatModel / Science。

  • 触发：任何上述子技能的关键词均可触发

  • 你的思维操作系统。基于日志、文章、工作文档提炼的 5 个心智模型 + 8 条决策启发式。
  • 触发：用 Lucas 的视角, Lucas 会怎么看, lucas perspective
  • 流程：问题分类 → Lucas 式研究（留存结构/经济闭环/竞品分析/溯源/可证伪性）→ Lucas 式回答（拆问题/找同构/给判断/留局限）
