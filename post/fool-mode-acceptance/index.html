傻逼模式验收

2026-11-11 • 3 分钟阅读 • 游戏设计 · 用户体验 · 思考方法

先说结论：验收需求的唯一合格标准，是一个什么都不知道的人，能不能顺着屏幕玩下去，并且在最重要的那个时刻爽到。带着设计者身份去验收，永远达不到这个标准。因为你脑里装着需求文档、数值表和开发排期，用户手里只有一块屏幕。

引发

SKM 的开箱子活动，验收完了。前面每一关都是同一个节奏：点击，开奖，奖励飞进右侧的收集框，获得感一格一格涨。到了最后一关——必得的大奖，玩家一路玩下去就是为了它——但是到最后却不需要点击，没有动画，没有音效，直接弹出结算总额，结束，用户会非常懵逼。

美术的反馈是：最后有一个获得大奖的界面，已经有强调获得感了，不需要再额外加动作。

这就是设计者视角的回答。在他脑里，「大奖界面」和「获得感」之间的因果链是完整的：我做了强调，所以用户感受到了强调。但用户脑里没有这条链。用户手里的事实是：最后一关，我点不了任何东西，我等来的只是一个弹窗结果而已。

前面九关用「点击 → 开奖 → 飞行 → 入框」训练出的节奏，在最高潮的地方突然断掉。获得感的积累在峰值处归零。这不是一个项目的问题。4K 的集卡迭代也一样：一大堆功能堆出来，没有任何引导，不知道怎么获得。功能是全的，方向是断的。

知识诅咒

1990 年，斯坦福的 Elizabeth Newton 做过一个实验。她让一组人在桌上敲出大家耳熟能详的歌，比如生日快乐歌，让另一组人猜歌名。敲之前，敲击者预测听者能猜对一半。实验结果：120 次敲击，猜对 3 次，2.5%。差距在敲击者脑里有旋律——他敲的每一个节奏，自己都听得见那首歌，他没法想象一个听不见旋律的人听到的是什么。这就是《粘住》里讲的知识诅咒「Curse of Knowledge」：一旦你知道一件事，就再也没法模拟不知道它的状态。

做设计的人就是敲节奏的那个。需求文档是旋律，你走查过的每一条路径都是旋律，你验收时「看见」的产品，是你脑里那个有旋律的版本；用户拿到的是桌面上那串孤零零的敲击声。「和美术沟通比我自己开发的成本还高」，根源就在这里：两边都以为自己把旋律传清楚了，实际传过去的只有节奏。来回拉扯的每一轮，都是在用语言补一条本来该由屏幕自己说清楚的话。

张小龙在微信八小时的内部分享里有一条，原文是：瞬间成为傻瓜用户。 训练自己瞬间成为傻瓜用户的能力，从傻瓜用户角度来体验产品，才能发现问题；注重第一次体验的感觉——用熟了就不能发现问题了。傻逼模式这个词难听，但准确。用户不傻，只是不知道你知道的事。张小龙还讲过：大家把用户当小白鼠、当数据，他把这些定义都推倒了——用户是人。正因为用户是第一次来的活人，才得有一个机制把设计者的知识清空，傻逼模式就是这个机制：把标准从「功能做完了」换成「陌生人玩爽了」。

我 2023 年写「什么样的产品才及格」，第一条就是出色的新手引导，第二条是第一印象。三年后同样的问题在验收现场反复出现，说明这是执行问题——道理都懂，进了验收就忘。忘的原因只有一个：没有规程，全靠自觉。而自觉敌不过知识诅咒，2.5% 对 50%，二十倍的高估。

规程

五条规则，验收时一条一条过：

  1. 禁开文档，只带屏幕。 需求文档、数值表、开发排期，验收前全部关掉，只看屏幕。
  2. 只信第一次点击。 每个界面、每次状态变化后，把自己当成头一次见这个界面的人，直接点，看知不知道下一步点哪。
  3. 亲手触发高潮时刻。 每个功能都有高潮那一帧：哪一关、哪个大奖、玩家最在意的哪个瞬间。找出来亲手按一遍，看手指动没动，奖励飞没飞。比如最后一关省掉点击，正反馈链就在峰值断掉了。
  4. 当场记录。 要多久知道下一步，过程中点错几次，高潮时刻有没有动画和音效反馈。
  5. 换人复核。 自己装不彻底，找一个没碰过这个功能的同事玩五分钟，在旁边看他怎么玩。

五条里任何一条不合格，这个需求就不算验收完。跟美术、开发有分歧，拿这三个数说话，不拿感觉说话。

闭环

王阳明讲知行合一：设计者的「知道」不算数，要降到「行」的层面才算知，用用户的身体把闭环走一遍，走不通就是不知道——验收就是行。维特根斯坦讲：凡不可言说者，必须保持沉默。反过来也成立，屏幕没有言说的，用户必须保持不知道；用户世界的边界是屏幕，文档里写了而屏幕上没有的，对用户等于不存在。铃木俊隆讲初心：初学者的心里有无限可能，专家的心里所剩无几。傻逼模式，就是主动把专家之心放下来五分钟。

最后回到方向。一大堆功能堆出来、没有任何引导，根子上是方向没想清楚：玩家为什么进这个功能，为了哪个瞬间。SKM 开箱子，答案明摆着——为了最后一关。那最后一关就该是全功能反馈最重的一帧：点击，动画，音效，飞行，入框，然后才是结算汇总。周边需求可以随做的人定，节奏留给自己；核心关卡的每一个高潮帧，值得亲自按一遍。把最好的反馈留给最重要的时刻，这本身就是方向。傻逼模式验收的是方向：一个什么都不知道的人，能不能感受到你想让他感受到的那个瞬间。
